> [!IMPORTANT]
> This project was **reverse-engineered** from a compiled APK. The original Dart source code **cannot be recovered** from a Flutter APK because Flutter compiles Dart into a binary blob (`kernel_blob.bin`). The UI and business logic must be rewritten based on your memory of the app.

## 🚀 How to Build

### Prerequisites
1. **Flutter SDK** ≥ 3.24.0 — [Install Flutter](https://docs.flutter.dev/get-started/install/macos)
2. **Android SDK** with API 36 — via Android Studio
3. **Java JDK 17**

### Setup & Run
```bash
# 1. Get dependencies
flutter pub get

# 2. Run on connected device
flutter run

# 3. Build debug APK
flutter build apk --debug

# 4. Build release APK (needs signing config)
flutter build apk --release
```

### local.properties (auto-generated by Flutter)
```properties
sdk.dir=/path/to/your/android/sdk
flutter.sdk=/path/to/your/flutter/sdk
```
